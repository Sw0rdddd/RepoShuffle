# 局限性

以下描述当前实现的边界，不是通过证明。实际执行结果见[测评状态](evaluation.md)，已复现问题及修复复验见[审查记录](review.md)。

## 公共边界

- `plan.ok` 和 `plan.compatibility` 只反映当前静态检查/推断，不证明功能等价，也不执行目标测试、安装依赖或验证所有动态路径。
- 文件位置、回溯和目录内容会变化；源码扫描、自定义加载器、构建插件与静态类型工具可能依赖物理布局。
- 符号链接不自动跟随；工作区一次选择一个子项目/语言，不保证跨子项目或跨语言联合构建等价。
- 未变化资源使用磁盘后备内容，但 Python 源码和改写内容仍可能缓存。输入字节、目录和计划变化需要重新规划。
- 存储前缀按 casefold 避让，规划检查文件及完整父目录集合的大小写/文件目录碰撞；这不代替目标文件系统上的实际发布验证。

## Python

- 模块路由使用额外标准库模块，不保证满足严格轻量导入白名单；逻辑别名不保持原目录列表。
- 普通物理导入可复用逻辑身份；显式 `SourceFileLoader`、`exec`、自定义加载器可能绕过路由。
- 资源和位置锚点按需保留，但静态路径分析不能穷尽动态表达式或外部路径。
- setuptools、Poetry、Hatch、Flit 有针对性适配；自定义后端、精确排除及特殊编译流程仍需独立验证。Flit 保持单包边界。
- 二进制扩展不参与重排；相邻 Python 回退文件识别不代表覆盖所有原生构建方式。

## Java

- 仅 random；保留文件名/字节及 package，不注入运行时路由，也不执行 Java 编译。支持范围是已识别的生产源码根，不是完整构建模型。
- 标准递归收集通常能编译包路径与物理目录不同的文件。显式根必须匹配已知字面 Maven 编译根；未知属性、继承和动态 Gradle 配置仍需实际构建验证。
- Maven 拒绝迁移已识别过滤器排除的文件或改变选择结果的布局。测评还要求每个迁移 Java 文件在两版均属于实际生产编译输入：Maven 使用 compile/inputFiles.lst 及生产 compile 阶段的实际 javac 文件对象诊断（支持非增量编译，不从 testCompile/Javadoc 取证）；并行 Maven 输出无法安全归属时不使用诊断补证。Gradle 按选中生产 JAR 的实际 class 输入关联成功 JavaCompile 的输出及源码，支持有归档证据的自定义 source set；禁用守护进程及缓存、强制重跑。其他编译器或改变 class 路径关联的字节码处理流程可能缺少证据，届时拒绝验收，不能靠类名猜测补齐。
- 原包路径后缀、原目录、字面文件名及已识别生产版本覆盖锚点只能减少路径敏感影响；非约定版本目录、动态文件路径、无边界的目录扫描仍可观察到重排。
- 外部/继承 POM、动态 Gradle 配置、注解处理、多版本/JPMS 编译、自定义源码扫描、自定义 Javadoc 选择、源码 JAR 的逻辑查找、资源打包和 IDE 仍需单独验证。声明源码根不等于完成适配。
- 未显式设置名称的 Gradle 工程可能从快照目录推导不同制品名，测评不掩盖此差异。
- 构建发现复用公共 gitignore 清单；忽略的子项目配置不做语义分析，其普通文件仍复制、保留原位。

## 文档引用

仅自动修正 `.md` / `.markdown` 中可明确解析、命中迁移文件的本地链接及引用式定义，不是完整 Markdown/Sphinx 解析器。保留 UTF-8 BOM、换行及 URL 查询/锚点，但不验证锚点有效性。

代码示例、行内代码、HTML、复杂语法、目录引用及 `.rst`、`.txt`、`.mdx`、`.html` / `.htm`、`.adoc` 仅对可识别的受影响路径警告，不改写。外部 URL、逻辑导入、测试/fixture 和 gitignored 文档不改写；被 Adapter 判为实现的文本不当作文档处理。未识别的自然语言/目录树引用可能遗漏，非 UTF-8 文档不处理。警告不代表所有引用已验证；修改及警告记录在 `manifest.json`。

## 复现

复现要求相同工具版本、输入和全部布局参数。当前布局版本 5、清单 schema 4；不承诺复现旧版布局。历史通过仅覆盖其明确的平台、版本及测试范围，不能外推到当前工作树或未执行的 CI。
