# 局限性

以下基于 [0.3.4 测评记录及运行版本说明](evaluation-0.3.4.md)。`plan.ok` 只表示静态检查未发现阻塞项；`plan.compatibility` 的构建适配和风险报告不是运行等价证明。

## 适用边界

- 模块路由需要额外标准库，不保证满足严格的轻量导入白名单；逻辑模块别名也不能保持原物理目录的内容列表。
- 普通物理模块导入可复用逻辑模块身份；显式 `SourceFileLoader`、`exec` 或自定义加载器仍可能绕过路由。
- 文件与回溯路径会变化。位置锚点按需保留，但路径分析不是完整 Python 解释器，无法穷尽动态表达式或外部路径。
- setuptools、Poetry、Hatch、Flit 有针对性构建验证；自定义后端、精确文件排除、特殊编译流程和静态类型解析仍需独立验证。Flit 按单包边界放置实现。
- 符号链接不自动跟随；Windows 的权限用例跳过，Linux 原生链接边界已验证。二进制扩展不参与重排，相邻 Python 回退文件识别不代表覆盖所有原生构建方式。
- 工作区一次选择一个子项目，不保证跨子项目构建依赖；大资源不常驻内存，但 Python 源码和改写内容仍会缓存。
- 本轮通过集只覆盖 10 个仓库在 Windows/Linux、Python 3.13、两种模式和两个种子下的指定范围，不能推断其他平台、版本、种子、源码分析器或原生验证框架均兼容。测评脚本会执行上游代码，应在隔离环境运行。

## 文档引用

仅自动修正 `.md` / `.markdown` 中可明确解析、命中迁移文件的本地链接及引用式链接定义，不是完整 Markdown/Sphinx 解析器。保留 UTF-8 BOM、换行、标题及 URL 查询/锚点；锚点有效性不保证。文件链接指向迁移后的实现，脚本执行命令仍应使用保留的入口。

代码块、行内代码、HTML、复杂语法、目录引用及 `.rst`、`.txt`、`.mdx`、`.html` / `.htm`、`.adoc` 只检查可识别的受影响路径并警告，不改写。外部 URL 和逻辑模块名不处理；测试/fixture 与 gitignored 文档保持原字节。目录树及自然语言中的隐含引用不能保证识别；警告不阻止生成，不代表所有文档均已验证。修改及警告可在 `manifest.json` 的 `changes` / `diagnostics` 查看。

## 复现边界

复现需要相同工具版本、输入及全部布局参数。当前布局版本为 5、清单 schema 为 3；不承诺复现其他工具或布局版本的输出。
