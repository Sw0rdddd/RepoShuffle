# 按源码根跨包混排

## 目标与规则

默认将同一源码根下多个 Python 包的可移动实现文件放进共享分配池，不依赖 layer、src 等特定名字。独立声明的源码根各自分配；只有一个包时继续使用包内存储。flat 模式统一消解重名，random 模式保持原文件名并分散同名文件，seed、complexity 和 max-depth 继续控制布局。

## 实现

1. 源码发现结果增加 `Inspection.source_roots`，记录逻辑包对应的源码边界。文件的 owner 和逻辑模块名保持原义。
2. 在生成包路由前按源码边界统一搬迁。多个兄弟包共享源码根下的 `_reposhuffle_code/`；同一落点的脚本参加相同分配，原位置恢复薄入口。
3. 包路由使用相对路径访问共享存储，运行时按实际导入包名前缀调整逻辑路由，支持 `src.alpha` 等容器前缀。
4. 保留初始化、位置锚点、资源、排除项及辅助目录。显式 setuptools 包清单和受 include 限制的 finder 加入共享存储包。
5. API/CLI 参数不变；计划记录 `allocation_scope=source-root` 和 `layout_version=4`。清单 schema 不变，同版本和输入参数可复现；不承诺复现布局版本 3。

## 验证

- 通过任意名字的源码根、兄弟包、同名文件、跨包及相对导入、动态导入、容器前缀、脚本、资源、独立源码根和排除规则回归。
- 构建 flat/random 的真实 wheel，在源码目录之外隔离导入，验证显式包列表及受限 finder 均包含共享存储。
- 运行工具完整测试、Ruff 和构建检查。
- 在 `repos/` 所有真实源码仓库执行 flat/random 转换和静态检查；对原版和转换版采用相同依赖和相同测试范围，记录命令、提交、结果、新增失败及限制。
- 本轮测评结果写入独立目录，不覆盖已有测评或修改上游断言；功能测试结果与转换静态检查分开报告。
