## 范围与方法

- 公开维护一套 **10 仓库通过集**；固定提交、依赖和测试范围见[配置](../evaluation/python.json)。通过集不代表工具限制已消除。
- 本地 Windows / Python 3.13.13，以及 Linux 原生文件系统 / Python 3.13.16；flat、random 均验证 seed=42、123，使用默认选择范围、complexity=0.7、max-depth=3。
- 原版与转换版使用相同依赖、命令和上游断言，严格比较 JUnit 节点及结果；仅按快照根和转换映射归一化路径。测试根目录显式隔离，不继承外围 conftest。
- **80 个转换布局全部匹配原版；100 个 wheel 均完成构建、安装及源码目录外导入。**各布局均有实际模块迁移，记录文件合计完成 86,340 次哈希核对。
